# Creator's Cove — public app

A free community web app for the Creator's Cove Facebook group (buy/sell/trade + games + giveaways).

- `index.html` — the Cove app (games, videos, giveaways). Open this file to use the app.
- `games/` — the 9 Cove games, linked from the app's Arcade tab. All play in the browser with no account and no sign-in.

Coins are saved on each player's own device, so everyone starts at 100 coins here. This site is a static snapshot; the app itself lives in Muse and is re-exported here when it changes.
